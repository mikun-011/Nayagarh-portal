Nayagarh Portal
A responsive web portal about Nayagarh, Odisha, "The Land of Hills, Temples & Chhena Poda". 
Explore its history, culture, temples, tourist places and famous food, find local facilities, and test yourself with a quick quiz.

[Live Demo](https://mikun-011.github.io/Nayagarh-portal/)

Features
- 📖 Detailed overview of Nayagarh: history, the Mandhata dynasty, culture, poets, folk traditions and festivals.
- 🛕 8 tourist places, each with its own page (Ladoo Baba Temple, Raghunath Temple, Fatehgarh Ram Temple, Kantilo Temple, Dakhinakali Temple, Jagannath Temple, Kuanria Dam and Balangi Bandha Park).
- 🍮 Famous food pages for Chhena Poda, Chhena Murki, Arisha Pitha and Kheer Kadam.
- 🏥 Facilities page covering transport, hospitals, schools, colleges and markets.
- ⏱️ Quiz with instant score to test your knowledge about Nayagarh.
- 📱 Fully responsive design for mobile, tablet and desktop.

Tech Stack
- HTML5
- CSS3
- JavaScript (vanilla)
- Deployed with GitHub Pages
